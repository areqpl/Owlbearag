# 🤝 Contributing to Owlbearag

Thank you for considering contributing to **Owlbearag**!

## Development Setup

1. Clone the repository:
   ```bash
   git clone https://github.com/areqpl/Owlbearag.git
   cd Owlbearag
   ```

2. Install in editable mode:
   ```bash
   pip install -e .
   ```

3. Run verification check:
   ```bash
   python -m py_compile owlbearag/*.py
   ```

## Commit Conventions

Follow the **Conventional Commits** specification:
- `feat:` New features
- `fix:` Bug fixes
- `docs:` Documentation changes
- `ci:` CI/CD and GitHub Actions updates
- `refactor:` Code refactoring

## Pull Request Guidelines

1. Create a descriptive feature branch (`git checkout -b feat/my-feature`).
2. Ensure code compiles cleanly without syntax errors or missing imports.
3. Open a pull request targeting `main`.
